1Connect Instagram

Use the Meta account that is admin of the Facebook Page linked to @tulz.lv.

How to get an access token (5 minutes)
  1. @tulz.lv must be an Instagram Business or Creator account linked to a Facebook Page (Instagram app → Settings → Account type).
  2. In Meta for Developers, open the app you already use for Facebook Login on tulz.lv. Add the Instagram use case / product (“Manage messaging & content on Instagram” or “Instagram API with Facebook Login”). If Meta doesn’t offer it because the app is a Consumer type, create a new Business-type app just for this.
  3. Open the Graph API Explorer, choose that app, click Generate Access Token and allow these permissions:
    instagram_basic instagram_manage_comments pages_show_list pages_read_engagement business_management
  4. Copy the token and paste it above. It is only sent to graph.facebook.com.

Connect once, never again: a token from the Explorer lasts ~1–2 hours. To make the saved login permanent, first open the Access Token Debugger, paste the token, click Debug, then Extend Access Token at the bottom, and paste that token here with “Remember” ticked. The tool turns it into a Page token that doesn’t expire. It stops working only if you change your Facebook password or remove the app.

Because only you (an app admin) use it on your own account, Meta’s App Review isn’t needed.
